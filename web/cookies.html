Cookie Policy

The current app does not use advertising cookies or analytics tracking.

Last updated: September 12, 2026

Current status

No cookie-consent banner is currently enabled. The application does not call document.cookie, load an analytics SDK, display advertising, or embed third-party media.

It does use browser storage for features that a visitor explicitly requests. Cookie and similar-technology rules can also cover local storage or other access to a device, so this policy identifies those uses transparently.

Third-party requests

The page currently requests Google-hosted fonts. Google OAuth redirects to Google when selected. Supabase handles account sessions and cloud storage when enabled. AI requests go directly to the selected provider only after you start a translation. These services may receive network metadata such as an IP address as part of delivering their requests; consult their policies.

Do you need consent?

For the current feature set, no analytics or marketing consent is being requested because those technologies are not installed. Strictly necessary storage may be exempt from consent in some jurisdictions, but transparency is still required and local-storage rules vary. Before adding analytics, advertising, personalization that is not necessary, or non-essential embeds, implement prior opt-in consent, equal reject/accept choices, withdrawal, and consent records.

This conclusion is based on the current code and should be rechecked by the operator before launch in each target market. UK guidance expressly covers storage or access technologies beyond traditional cookies; EU and other national rules may differ.
