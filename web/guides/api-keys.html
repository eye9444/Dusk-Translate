DuskTranslate / Setup

Bring your own AI key.

DuskTranslate sends translation requests directly from your browser to the provider you select. Create a key with one of the providers below, then paste it into the editor when you translate.

Last reviewed: September 12, 2026

Keep your key private. DuskTranslate keeps the key in the current editor session and does not put it in project snapshots. Provider keys can still incur charges or be abused if exposed, so never commit them, share screenshots containing them, or paste them into a public issue.

Google AI Studio

Google AI Studio provides Gemini API keys. Availability, model access, quotas, safety restrictions, and billing depend on your Google account and region.

1. Open the key page

Sign in to Google AI Studio API keys.

2. Create or select a project

Use the project selector shown by Google AI Studio. If prompted, accept the applicable Google AI terms and configure billing or limits required for the model you want to use.

3. Create and copy the key

Choose Create API key, select the intended project, and copy the key once. Treat a key beginning with AIza as a secret.

4. Use it in DuskTranslate

Open a project, choose a Google AI Studio model, paste the key into the API key field, and start a translation. The key is not included in the saved project or cloud snapshot.

Read Google's API-key documentation for current key restrictions, quota, and billing details.

OpenRouter

OpenRouter provides one API endpoint for models from multiple providers. Model availability, free-tier limits, rate limits, and provider routing can change, so check the current model page before relying on a model.

1. Open your key settings

Sign in to OpenRouter key settings.

2. Create a key

Choose Create key, give it a recognizable name such as DuskTranslate browser, and set the smallest spending limit that fits your testing.

3. Choose an available model

Review the OpenRouter models list. DuskTranslate's model menu only includes the models configured by this build; a provider can still reject a model because of quota, eligibility, or safety rules.

4. Use it in DuskTranslate

Select an OpenRouter model, paste the key into the API key field, and translate. The request is sent directly to OpenRouter from the browser.

Read OpenRouter's API documentation for current authentication and usage information.

Safety checklist

  • Use provider-side restrictions and low spending limits where available.
  • Do not put a provider key in HTML, JavaScript, Git, screenshots, or a shared project backup.
  • Revoke or rotate a key immediately if it appears in a public place.
  • Remember that uploaded books and prompts are sent to the provider when you start a translation. Only process content you are authorized to use.
  • For a shared computer, leave "Remember me" unchecked and clear the editor session when finished.

Troubleshooting

Nothing is returned

Check the selected provider, model availability, key format, browser network access, provider quota, and safety response. Try a shorter chapter or switch to another configured model. DuskTranslate cannot bypass provider limits.

The key works elsewhere but not here

Confirm that the model belongs to the selected provider and that the key is allowed to make browser-originated requests. Rotate the key if it may have been exposed.
